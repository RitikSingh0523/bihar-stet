
## 11. ICT in Education

- **ICT** = Information and Communication Technology: devices + software + networks to create, store, share information. Roles: access to content, anytime-anywhere learning, interactivity, personalised learning, administration, assessment, teacher training, reaching remote areas.
- **Digital divide**: gap between those who **have access** to ICT/internet and those who do not (by income, region, gender, skills). **Digital literacy** reduces it.
- **OER (Open Educational Resources)**: freely accessible, openly licensed (e.g., Creative Commons) teaching-learning materials. **LMS** (Learning Management System): platform for courses, content, tests, tracking - **Moodle** is a popular **open-source LMS**; others: Google Classroom, Blackboard, Canvas.
- **MOOC** = **Massive Open Online Course**: large-scale, open-enrolment, internet-based course (Coursera, edX, Udacity, SWAYAM).
- **ePub** = open **electronic publication** e-book format (reflowable text, adapts to screen size); **PDF** is fixed layout.

### Modes of learning

| Mode | Meaning |
|---|---|
| **E-learning** | learning via electronic media/internet |
| **Online learning** | synchronous (live) or asynchronous (recorded) over internet |
| **Blended learning** | **combination of face-to-face classroom teaching with online/ICT learning** (e.g., flipped classroom, SWAYAM + class) |
| **Mobile learning (m-learning)** | via smartphones/tablets |
| **CAI / CAL** | computer-assisted instruction/learning (drill, tutorial, simulation) |
| **Smart class** | classroom with interactive digital board/projector, digital content, internet |
| **Virtual classroom / virtual lab** | online live class; simulation-based experiments |
| **Distance/open learning** | IGNOU, NIOS (open schooling) |

### Indian ICT initiatives

| Initiative | Key facts |
|---|---|
| **SWAYAM** | **Study Webs of Active-Learning for Young Aspiring Minds**; national **MOOC platform** (launched 2017, MoE/AICTE with NPTEL, Google, Microsoft); **school (class 9-12) to postgraduate**; free; each course = **4 quadrants** (video lecture, reading material, self-assessment/quiz, discussion forum); credit transfer allowed |
| **SWAYAM Prabha** | **32 DTH educational TV channels** (24×7, broadcast through GSAT-15 satellite) |

- **National Policy on ICT in School Education (2012)**; **ICT@Schools** scheme.
- **Cyber safety**: strong passwords, avoid phishing, respect copyright (plagiarism), netiquette, protect privacy.

**⚡ Exam tip:** SWAYAM = MOOC platform; SWAYAM Prabha = DTH TV channels; DIKSHA = QR-coded school content; e-Pathshala = NCERT e-books; NPTEL = IITs video courses; EDUSAT = 2004 education satellite; Gyan Vani = educational FM radio; Moodle = open-source LMS; blended = classroom + online.

## 12. Teaching of Computer Science (Pedagogy)

### Aims and approach
- Develop **computational thinking**, problem-solving, logical reasoning, programming and digital citizenship. CS is **practical subject** - theory:practical balanced (typically 70:30 in CBSE XI-XII; Python/SQL).
- **Computational thinking elements**: **decomposition**, **pattern recognition**, **abstraction**, **algorithm design** (also evaluation/debugging). *Generalisation* = finding commonalities across cases; *abstraction* = hiding unnecessary detail. Not a core element: memorisation/typing speed.
- **Before writing a program, the student should first understand the problem and design an algorithm/flowchart (pseudocode)**, then code, test, debug.

### Methods in CS

| Method | Use |
|---|---|
| **Lecture-cum-demonstration** | show IDE, execute code live (live coding) |
| **Laboratory/practical** | hands-on programming; lab record + **viva voce**; tests actual skill, understanding, confidence |
| **Project/Problem-based** | mini projects (library system, quiz app); teamwork |
| **CS Unplugged** | **computing concepts taught without computers** (cards, games, physical activities), e.g., sorting networks, binary numbers with cards |
| **Pair programming** | two learners, one computer: **driver** (types) and **navigator** (reviews); swap roles; reduces errors, peer learning |
| **Dry run / tracing** | executing code on paper step by step with variable table - **helps understand logic, find logical errors, predict output** |
| **Block-based languages (Scratch, MIT; Blockly, App Inventor)** | drag-and-drop; avoids syntax errors, **visual/engaging for beginners**, concepts (loops, events) first |
| **Text-based (Python)** | **simple readable syntax**, interpreter, interactive shell, free; widely first language |
| **Worked examples / PRIMM** (Predict-Run-Investigate-Modify-Make), **Use-Modify-Create** | scaffolded learning |
| **Analogies and models** | stack = pile of plates; queue = ticket line; variable = labelled box; recursion = Russian dolls |
| **Flipped classroom / blended / MOOC** | content online, coding practice in class |
| **Debugging games, error analysis** | find syntax, runtime, logical errors; **error analysis** = classify/examine mistakes in code |

### Common novice misconceptions
- A variable stores multiple values / "=" means mathematical equality (not assignment); program executes all lines simultaneously; loop condition checked only at the end; computer "understands" intent; output of a line persists; `print(x)` changes x; confusing variable name and string; off-by-one errors in `range()`; mixing `=` and `==`; assuming input() returns number.
- Remedies: tracing, concrete examples, immediate feedback, error discussion, peer review.

### Assessment in CS
- Practical exam + viva, lab record, programming assignments, project, quizzes, rubrics for projects, portfolios, debugging tasks, MCQs on code output, **e-assessment** (auto-graders).
- Objectives: knowledge (syntax), understanding (trace), application (write programs), skill (debug), attitude (ethics).
- **Ethics and digital citizenship**: copyright, plagiarism, cyber-bullying, privacy, licensing (open source).

**⚡ Exam tip:** Dry run = trace to understand logic/find errors. Scratch = block-based for beginners; Python = simple syntax for first language; CS Unplugged = no computers; pair programming = driver + navigator; first design algorithm, then code.

## 13. NEP 2020 - Key Provisions

- **NEP 2020**: approved by Union Cabinet on **29 July 2020**; **Committee: Dr K. Kasturirangan**. Third NEP (after 1968, 1986/92). Replaced NPE 1986. **MHRD renamed Ministry of Education.**
- Vision: universal, equitable, high-quality education; "India-centric"; aligned with SDG-4 (2030).

### Structure: 5+3+3+4 (replaces 10+2)

| Stage | Age | Classes |
|---|---|---|
| **Foundational** (5 yrs) | **3-8** | 3 yrs Anganwadi/pre-school + Grades 1-2 |
| **Preparatory** (3 yrs) | **8-11** | Grades 3-5 |
| **Middle** (3 yrs) | **11-14** | Grades 6-8 |
| **Secondary** (4 yrs) | **14-18** | Grades 9-12 (two phases, multidisciplinary, flexible subjects, **no rigid arts/science/commerce separation**) |
- Universal ECCE; **NIPUN Bharat** (2021): **FLN (Foundational Literacy and Numeracy)** for every child by **Grade 3 by 2026-27**.
- **Language**: medium of instruction **at least till Grade 5, preferably Grade 8 and beyond = home language/mother tongue/regional language**; **three-language formula** (flexible, no imposition); Sanskrit and classical languages options; Indian Sign Language standardised.
- **Curriculum**: reduce content, **core essentials**, experiential/art-integrated, **coding from Grade 6**, vocational education from **Grade 6** with internships, **bagless days**, **Board exams low stakes - twice a year, testing core concepts/competency**.
- **Assessment**: **PARAKH** (National Assessment Centre); **holistic 360° progress card**; **school exams in Grades 3, 5, 8**.
- **Equity**: **Special Education Zones, Gender Inclusion Fund**, SEDGs (socio-economically disadvantaged groups).
- **Teachers**: **minimum degree = 4-year integrated B.Ed.** (by 2030); **NCTE** to frame **NCFTE**; **ITEP = 4-year Integrated Teacher Education Programme** (after Class 12); **TET** for all stages; **50 hours CPD/year**; National Professional Standards for Teachers (**NPST**); merit-based, transfers limited.
- **Higher education**: **GER 26.3% → 50% by 2035**; **HECI = single regulator** (excluding medical & legal) with four verticals: **NHERC** (regulation), **NAC** (accreditation), **HEGC** (funding), **GEC** (standards setting); **multidisciplinary (MERU) universities**; **multiple entry/exit** in UG (certificate 1 yr, diploma 2 yr, degree 3-4 yr; **4-year UG** with research); **Academic Bank of Credit (ABC)**; **M.Phil discontinued**; affiliated college system phased out in 15 years; **NRF** (National Research Foundation); **NTA** conducts common entrance (**CUET** university entrance); foreign universities may set campuses.
- **APAAR** (**Automated Permanent Academic Account Registry**): **"One Nation One Student ID"**, linked with **ABC/DigiLocker**.
- **Financing**: public expenditure on education **6% of GDP** (Centre + States); currently ~4.6%.
- **Technology**: **NETF**; digital content; Virtual labs; DIKSHA.
- **Adult education**, **Indian knowledge systems**, **National Mission on FLN**, **School complexes** (clusters), **School Quality Assessment & Accreditation Framework (SQAAF)**; **SCERT** to prepare SCF.
- Five pillars: Access, Equity, Quality, Affordability, Accountability.

**⚡ Exam tip:** 5+3+3+4 = 3-8 foundational, 8-11 preparatory, 11-14 middle, 14-18 secondary. Mother tongue at least till Grade 5 (preferably 8). 6% GDP; GER 50% by 2035; HECI single regulator; MHRD → Ministry of Education; ITEP 4-year; APAAR = student ID.

## 14. Regulatory Bodies, RTE and Schemes

### Bodies

| Body | Year | Function |
|---|---|---|
| **UGC** (University Grants Commission) | 1956 (Act; formed 1953) | coordination and **standards of university education**, grants to universities |
| **AICTE** (All India Council for Technical Education) | 1987 (statutory) | planning/approval of **technical education** (engineering, MCA, management, pharmacy) |
| **NCERT** (National Council of Educational Research and Training) | **1961** (Delhi) | **curriculum framework (NCF), model textbooks**, research, training; advises Centre/States |
| **NCTE** (National Council for Teacher Education) | **1995** (NCTE Act 1993) | **regulates teacher education**, recognition of institutions, norms/curriculum framework for teacher education (**NCFTE**) |
| **SCERT** | State level | state curriculum, textbooks, teacher training (Bihar SCERT, Patna); DIET at district level |
| **NAAC** (National Assessment and Accreditation Council) | 1994 (Bengaluru, autonomous of UGC) | **assessment & accreditation** of HEIs (grades A++... C) |
| **NBA** | 1994 | accreditation of **technical programmes** |
| **CBSE** | 1962 | board for affiliated schools; **NIOS** = open schooling; **NIEPA** = educational planning/administration |
| **NTA** (National Testing Agency) | 2017 | conducts common entrance tests (JEE Main, NEET, CUET, UGC-NET) |
| **IGNOU** | 1985 | open and distance learning |
| **MoE** | | formerly MHRD (renamed 2020) |
- NEP 2020 -> **HECI** will replace UGC, AICTE (and NCTE part) as single regulator.
- Teacher recruitment eligibility: **TET/CTET** (CTET by CBSE) - STET is the state-level eligibility test.

### Right to Education (RTE) Act 2009
- **86th Constitutional Amendment (2002)** inserted **Article 21A** - free and compulsory education for children **6-14 years**; Act in force **1 April 2010**.
- Provisions: **25% reservation** for disadvantaged/weaker sections in private unaided schools; **no detention and no board exam till elementary completion**; **no capitation fee, no screening test**; **PTR 30:1 (primary), 35:1 (upper primary)**; **no corporal punishment/mental harassment (Sec 17)**; **CCE and no-board-exam (Sec 29)**; School Management Committees (SMC); qualified teachers (TET); neighbourhood school; prohibits private tuition by teachers; Article 45 (earlier 0-6 ECCE), Article 51A(k) parental duty.
- **Mid-Day Meal** (1995; now **PM POSHAN**) supports enrolment and nutrition.

### SSA, RMSA, Samagra Shiksha

| Scheme | Key |
|---|---|
| **SSA** (Sarva Shiksha Abhiyan) | **2001**; universal elementary education (6-14); partnership Centre-State; vehicle for RTE |
| **RMSA** | **2009**; universalise secondary (Classes 9-10) |
| **RUSA** | 2013; higher education |
| **Samagra Shiksha** | **2018**; **integrated scheme** merging **SSA + RMSA + Teacher Education** - **pre-school to Class 12**; one-school-continuum; digital, inclusive, quality, vocational |
| **PM SHRI** | 2022; model schools showcasing NEP |
| **NISHTHA / NIPUN Bharat** | teacher training / FLN mission |
| **Beti Bachao Beti Padhao**, **Kasturba Gandhi Balika Vidyalaya**, **Navodaya Vidyalayas (NPE 1986)**, **Operation Blackboard (1987)**, **DPEP (1994)** | other flagships |

**⚡ Exam tip:** NCERT = NCF + textbooks; NCTE = teacher education regulation; UGC = universities; AICTE = technical education; NAAC = accreditation. RTE: Art. 21A, ages 6-14, 25% reservation, no detention, no corporal punishment. Samagra Shiksha = SSA + RMSA + TE (2018).
